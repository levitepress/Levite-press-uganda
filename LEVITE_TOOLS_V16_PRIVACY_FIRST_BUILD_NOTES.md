# Levite Tools V16 — Privacy-First Build

- Automatic browser tools are designed to process supported files locally on the customer's device.
- Removed localStorage storage of professional request details from the automatic tool workspace.
- Added finished-work preview and explicit Save / Download actions for image, PDF and OCR text results.
- Fixed OCR PDF page creation when text exceeds one page.
- PDF split remains local; each page is offered through the browser download flow.
- Professional request button prepares an email to levitepressug@gmail.com; files are not silently uploaded.
- Updated Levite Tools messaging and future-tools page to explain the privacy-first model.
- Expanded privacy.html with local processing, professional-service handling, retention and security language.
- No cloud backend connection was added.

## Important
Local processing depends on browser/device support and available memory. Some advanced document conversions still require a professional service.
